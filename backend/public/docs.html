API Documentation

Welcome to the AeroBite API documentation. This API powers the AeroBite food delivery platform. Authentication is required for most endpoints.

Authentication

All API requests must include a Bearer token in the header.

Authorization: Bearer <your_token>

Key Endpoints

GET
/api/health

Check system status and metrics.

POST
/api/auth/login

Authenticate user and retrieve token.

GET
/api/orders

Retrieve list of orders (requires auth).
